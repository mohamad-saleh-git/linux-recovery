# linux-recovery

My personal notes for getting my Linux skills back on track.

I'm learning with the help of ChatGPT and [Jadi](https://jadi.net)'s Linux course.

## What's inside

- [`text.txt`](text.txt): a cheat sheet of the Linux commands I use, with short explanations and examples.

## Topics covered

- Recommended terminal setup (zsh, Powerlevel10k, eza, bat, btop, tmux, fastfetch)
- Navigation, files and directories
- Viewing and editing files
- System information and process management
- Users and permissions
- SSH and links
- Package management (`apt`)
- Monitoring memory and CPU

## Note

These notes are for personal use. Commands like `rm -rf` and `shred` are destructive, so double-check before running them.
